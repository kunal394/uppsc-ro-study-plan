Intel Core i9 refers to which kind of computer component?

Answer: A. Processor

Core i9 is a processor family. Distinguish processing hardware, storage hardware and software.

Selected adapted PYQ · 2025 · Q31 · PDF p7

A conventional Ethernet MAC address has how many bits?

Answer: D. 48

The standard EUI-48/MAC address used in conventional Ethernet has 48 bits, typically displayed as six octets. IP address sizes are a different concept.

Which item is an application suite rather than an operating system?

Answer: B. Microsoft Office

Microsoft Office is productivity application software. Linux, Windows and Unix belong to operating-system families.

Selected adapted PYQ · 2025 · Q65 · PDF p14

After Chandrayaan-3's successful 2023 soft landing, India became which country in the sequence of nations achieving a lunar soft landing?

Answer: C. Fourth

India became the fourth after the Soviet Union, United States and China. This is the historical 2023 milestone, not a prediction about later missions.
